Optional Software Scanner: Run the lightweight scanner script on any Windows endpoint to generate a software and running process inventory JSON. Sysmon-Generator will analyze the report, match found software against known profiles, and propose tuned Sysmon inclusion/exclusion rules.

Step 1: Run Scanner on Endpoint

Open an administrative PowerShell prompt on the target machine and run:

powershell.exe -ExecutionPolicy Bypass -File .\scripts\scan_software.ps1

This produces software_scan_report.json with installed software and running process signatures.
